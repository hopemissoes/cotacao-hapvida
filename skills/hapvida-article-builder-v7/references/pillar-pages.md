## ⚠️ CRITICAL TRIANGLE — Tabela Regional Subpages (Article Type TR)

⚠️ **Para artigos TR** (subpáginas-filha de `/tabela-de-preco-hapvida/`), 3 pillars formam um **triângulo crítico de anti-doorway**. Estas pillars frequentemente estão anexadas ao projeto Claude como arquivos `.txt`, mas isso não autoriza reprodução — pelo contrário, estar no projeto serve para Claude saber o que existe e o que NÃO repetir.

Estas 3 pillars listam centenas de fatos sobre Hapvida que **NÃO PODEM aparecer no artigo TR**, mesmo em forma resumida.

Antes de produzir qualquer artigo TR, Claude DEVE:

1. Abrir as 3 pillars (URL ou arquivo `.txt` no projeto)
2. Listar mentalmente o que cada uma cobre
3. Garantir que o artigo TR só toque esse conteúdo em **bridges curtos** (1-2 frases + link)
4. Aplicar substitution test antes de finalizar

### Substitution test específico TR — 3 testes obrigatórios

1. **Test 1 — Cidade-swap:** trocar [cidade] por outra do mesmo grupo tarifário. Se PT1+PT4+PT5+FAQ continuarem 100% válidos, é doorway de cluster.
2. **Test 2 — Pillar-swap:** ler o bloco PT2 sem o link à pillar empresarial. Se o leitor consegue extrair os mesmos fatos que estão na pillar (modalidades, reajustes, direitos), é doorway de produto. Cortar.
3. **Test 3 — Image-removal:** remover as 2 imagens mentalmente. Se a página continua valendo a pena indexada, ela está sobrecarregada. Se vira esqueleto, está calibrada.
